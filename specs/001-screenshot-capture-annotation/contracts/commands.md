# 契約：選單、快速鍵與工具鍵

這是使用者面對的命令契約，供實作與手動測試對照（FR-001、FR-028）。

## 全域

| 動作 | 預設快速鍵 | 備註 |
|------|-----------|------|
| 開始擷取 | `⌃⇧4` | 可在偏好設定變更；被占用時顯示警告 |

## 主選單（編輯器或資料庫視窗開啟、Dock 圖示出現時）

所有動作都有選單項目（FR-028）。App 層動作與選單列圖示相同；編輯器動作沿 responder chain 送到目前的編輯器視窗，沒有編輯器時自動停用。

| 選單 | 項目 | 快速鍵 |
|------|------|--------|
| TracePixels | 偏好設定… | `⌘,` |
| 檔案 | 擷取區域／擷取視窗／擷取全螢幕 | `⌃⌥⌘R`／`⌃⌥⌘W`／`⌃⌥⌘F`（僅 App 啟用時；全域快速鍵另見上表） |
| 檔案 | 開啟資料庫… | `⇧⌘L` |
| 檔案 | 另存新檔…、分享…、關閉視窗 | `⇧⌘S`、—、`⌘W` |
| 編輯 | 復原、重做、複製影像 | `⌘Z`、`⇧⌘Z`、`⌘C` |
| 編輯 | 刪除所選標註、清除裁切 | —（刪除用 `⌫`，在畫布處理） |
| 編輯 | 移到最上層／上移一層／下移一層／移到最下層 | `⌥⌘]`／`⌘]`／`⌘[`／`⌥⌘[` |
| 工具 | 十一個工具（選取…裁切） | 單鍵（`V` `A` `L` `R` `O` `P` `H` `T` `N` `B` `X` `C`）在畫布處理，選單項目顯示對應的鍵 |
| 檢視 | 放大／縮小／符合視窗 | `⌘+`／`⌘-`／`⌘0` |
| 檢視 | 調整輸出大小… | `⌥⌘I` |

## 擷取覆蓋層

| 按鍵 | 動作 |
|------|------|
| `R` | 切換為區域模式（預設） |
| `W` | 切換為視窗模式 |
| `F` | 切換為全螢幕模式 |
| 拖曳／點擊 | 區域：拖曳選取，放開即確認；視窗：點擊高亮的視窗；全螢幕：點擊要擷取的顯示器 |
| `Esc` | 取消擷取，不產生任何副作用 |

覆蓋層上方顯示三個模式按鈕（區域／視窗／全螢幕）作為滑鼠操作替代。區域模式拖曳期間顯示寬高、游標座標與放大鏡。

## 選單列項目

- 擷取區域／擷取視窗／擷取全螢幕
- 開啟資料庫…
- 偏好設定…
- 結束

## 編輯器工具

| 工具 | 鍵 |
|------|----|
| 選取 | `V` |
| 箭頭 | `A` |
| 線條 | `L` |
| 矩形 | `R` |
| 橢圓 | `O` |
| 手繪筆 | `P` |
| 螢光筆 | `H` |
| 文字 | `T` |
| 步驟標記 | `N` |
| 模糊 | `B` |
| 馬賽克 | `X` |
| 裁切 | `C` |

在文字輸入中，單鍵工具快捷鍵不生效。

## 編輯器動作

| 動作 | 快速鍵 |
|------|--------|
| 復原／重做 | `⌘Z`／`⇧⌘Z` |
| 刪除所選標註 | `⌫` |
| 複製影像 | `⌘C`（無標註選取時） |
| 另存新檔… | `⇧⌘S` |
| 分享… | 工具列按鈕與選單項目 |
| 放大／縮小／符合視窗 | `⌘+`／`⌘-`／`⌘0` |
| 移到最上層／最下層 | `⌥⌘]`／`⌥⌘[` |
| 關閉視窗 | `⌘W`（編輯內容已自動保存，不跳出警告） |

## 資料庫視窗

- 雙擊縮圖：重新開啟編輯。
- `⌫` 或右鍵「刪除」：跳出確認對話框，確認後才永久刪除（FR-022）。
