# 契約：選單、快速鍵與拖曳（增補）

延伸[功能 001 的命令契約](../../001-screenshot-capture-annotation/contracts/commands.md)。未列出的項目不變。

## 選單列項目（新順序）

- 擷取區域／擷取視窗／擷取全螢幕
- **開啟圖片…** `⌘O`（新）
- 開啟資料庫…
- 偏好設定…
- 結束

在沒有任何視窗、Dock 圖示隱藏時也可使用（FR-031）。顯示檔案選擇視窗前會先讓 App 成為前景。

## 主選單「檔案」（新增兩項）

| 項目 | 快速鍵 | 行為 |
|------|--------|------|
| **開啟圖片…** | `⌘O` | 同選單列：選檔 → 匯入 → 開編輯器（至多 5 個） |
| **匯入…** | `⇧⌘I` | 選檔 → 只匯入資料庫，不開編輯器；隨時可用，不需先開資料庫視窗 |

位置：「擷取全螢幕」之後、「開啟資料庫…」之前放「開啟圖片…」；「開啟資料庫…」之後放「匯入…」。

## 檔案選擇視窗

- 可選類型：圖片（`public.image`）；允許多選；不可選資料夾。
- 取消：無任何副作用。
- 標題與按鈕：「開啟圖片」／「匯入圖片」，確認鈕「開啟」／「匯入」。

## 資料庫視窗

| 元件 | 行為 |
|------|------|
| 底部列「匯入…」按鈕 | 同 `⇧⌘I` |
| 拖放目標（整個視窗，含空白狀態） | 接受檔案 URL；拖曳經過時顯示強調色邊框；放開 → 只匯入，不開編輯器 |
| 縮圖卡片 | 匯入項目在日期旁顯示「匯入」小圖示；滑鼠停留的提示顯示原始檔名；VoiceOver 標籤附上「匯入自 <檔名>」 |
| 空白狀態說明 | 「擷取的影像會自動出現在這裡。也可以按「匯入…」或把圖片拖曳到這個視窗。」 |

## 匯入後的回報

- 全部成功：不跳訊息。
- 有失敗或略過：單一對話框，內容為成功數量、略過的非檔案項目數量、失敗檔案（最多 8 筆，含檔名與原因，其餘以「…等 N 個」帶過）。
- 超過 5 個要開啟：成功後在同一對話框（或單獨一則）提示「其餘 N 張已在資料庫中」。

## Finder 與 Dock

- Finder 對圖片檔「打開方式」清單出現 TracePixels（`LSHandlerRank = Alternate`，不成為預設程式）。
- 拖圖片檔到 Dock／應用程式圖示：行為同「開啟圖片…」選好檔案之後（匯入並開編輯器，至多 5 個）。
- 冷啟動由 Finder 開啟：啟動完成後處理，不顯示多餘視窗。
